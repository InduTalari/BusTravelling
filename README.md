# 🚌 BusTravelling - Bus Booking System

## 📌 Project Overview
BusTravelling is a full-stack bus booking application that allows users to browse buses, select seats, book tickets, and manage their bookings.

## 🚀 Features

### Frontend
- User Login & Registration
- View Available Buses
- Search Buses
- Seat Selection
- Book Tickets
- View My Bookings
- Responsive UI

### Backend
- REST APIs using Django REST Framework
- User Authentication
- Bus Management
- Seat Management
- Booking Management
- Database Integration

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Python
- Django
- Django REST Framework

### Database
- SQLite3

## 📂 Project Structure

```
BusTravelling/
│
├── travels/          # React Frontend
│
└── django/
    └── travels/      # Django Backend
```

## ⚙️ Installation

### Frontend

```bash
cd travels
npm install
npm run dev
```

### Backend

```bash
cd django/travels
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## 🌐 API

Backend runs on:

```
http://127.0.0.1:8000/
```

Frontend runs on:

```
http://localhost:5173/
```
